# Changelog Alexa Devices

## [0.9.1] - 2026-11-27
- Updated `aioamazondevices >= 18.0.2`.
- Real-time HTTP/2 push for alarms, timers, and reminders (`next_alarm`, `next_timer`, `next_reminder`).
- Fixed `media_state` reporting (`player_state`).
- OAuth proxy, session reset, and UI polling fixes.

## [0.9.0] - 2026-11-14
- Initial stable release for Jeedom v4 / v4.4+.
- Real-time Amazon AVS HTTP/2 push stream.
- Automatic Echo and Alexa device discovery.
- TTS, announcements, text voice commands, volume slider, media player, DND.
- Voice transcription history.
- Interactive 2FA OTP authentication wizard.
- Dedicated Dashboard and mobile widgets.
- Multilingual support (FR, EN, ES).
